# Мои цели на семестр (курс «Инструменты DevOps»)

1. **Уверенно освоить Git и GitHub Flow**: свободно работать с ветками, Pull Request и Code Review, уметь разрешать merge-конфликты и аккуратно приводить историю коммитов в порядок с помощью rebase.
2. **Контейнеризовать свой пет-проект**: упаковать веб-приложение To-Do List (Node.js) в Docker-контейнер, написать собственный Dockerfile и docker-compose.yml.
3. **Настроить CI/CD для пет-проекта**: собрать автоматический пайплайн в GitHub Actions, который при каждом push будет прогонять тесты и собирать образ приложения.
